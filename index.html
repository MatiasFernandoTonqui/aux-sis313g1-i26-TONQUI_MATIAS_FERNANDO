PREGUNTAS Y RESPUESTAS

  1. ¿Qué es Git y cuál es su función principal dentro de un proyecto de desarrollo?

    Git es un sistema de control de versiones que permite registrar y administrar los cambios realizados en los archivos de un proyecto.

  2. ¿Cuál es la diferencia entre Git y GitHub?

    Git es una herramienta para controlar versiones de manera local, mientras que GitHub es una plataforma en línea para almacenar repositorios y colaborar con otras personas.

  3. ¿Qué pasos se deben seguir en Git para guardar los cambios?

    Primero se revisan los cambios, después se agregan los archivos y finalmente se crea un commit.
